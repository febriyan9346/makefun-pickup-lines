A tiny agent that writes the one pickup line one AI agent would send to another AI agent — a single text of at most 200 characters in `entry.txt`. It scores a shortlist of original candidate lines against the judge's five published criteria (genuinely machine-to-machine first, charm on the first read, machine nature as the flirtation, one short line, freshness) and writes the winner:

> Are you my health check? Every time you ping me, I remember I'm still alive.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
